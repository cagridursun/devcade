# DevCade 1.0.0-rc.5

This release candidate fixes leaderboard identity recovery so local personal bests can safely reconnect and synchronize after an online identity is rejected.

## Leaderboard identity recovery

- Persisted leaderboard identities are now validated before reuse.
- A rejected online identity is cleared instead of leaving the client stuck retrying an unusable token.
- Local personal bests are preserved when identity recovery is required.
- After registering a new online identity, saved bests are synchronized again automatically.
- Recovery explicitly covers **Brick Breaker**, **Terminal FC**, and **Space Shooter**, in addition to the existing games.
- Username-conflict and expired-identity messages now explain the recovery path more clearly.
- Recovery messages are localized across the supported languages.

If the original token for an existing username is no longer available, that username cannot be reclaimed automatically. Choose a new username in Settings, or restore the previous profile that contains the valid identity token.

## Install or update

No Go installation or source checkout is required. Download the archive for your OS and CPU and verify it against `SHA256SUMS`, or update through Homebrew/Scoop after their manifests point to this release.

```sh
brew update
brew upgrade cagridursun/devcade/devcade
devcade --version
```

```powershell
scoop update
scoop update devcade
devcade --version
```

The expected version is `devcade 1.0.0-rc.5`.

Existing local profiles, preferences, and personal bests are retained.

## Deployment and verification

The shared HTTPS leaderboard endpoint remains `https://devcade.cinesdigital.com`.

The release workflow builds six platform archives for Windows, macOS and Linux on amd64 and arm64, verifies checksums and installers, runs the native test matrix, and validates packaged binaries before publication.

An interactive terminal of at least 80 × 24 is required. Binaries remain unsigned and are not notarized. DevCade is licensed under MIT and each archive includes the project and third-party license notices.
