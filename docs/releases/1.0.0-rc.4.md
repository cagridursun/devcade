# DevCade 1.0.0-rc.4

This release candidate gives all seven DevCade games a unified terminal-arcade visual system and refreshes the public project presentation with real gameplay captures.

## Arcade visual refresh

All seven games now share the same phosphor-inspired presentation while keeping their existing gameplay rules and controls.

- **Snake** uses the shared arcade frame, dotted field, compact HUD and speed meter.
- **Block Drop** renders falling pieces, ghost position and the stack with chunkier arcade glyphs and a dedicated next-piece panel.
- **Maze Chase** stretches the maze across the full play area with clearer player, chaser, vulnerable and power-pellet sprites.
- **Blast Grid** expands the arena across the full frame with clearer walls, crates, bombs, flames, bots and player markers.
- **Brick Breaker** maps its physics field directly to the visible arena so ball collisions line up with the displayed side walls.
- **Terminal FC** gets clearer home/away team colors, a corrected center circle and fixed active-player glyph rendering.
- **Space Shooter** uses the shared frame, arcade sprites, special-charge meter and updated special-attack sweep visuals.

The Colorful palette now maps gameplay roles to consistent phosphor, warning, danger and team colors across the collection.

## README and website

The README showcase and GitHub Pages site now use **real gameplay GIFs captured from all seven games**.

- The repository hero shows a seven-game gameplay reel.
- The website hero shows the same real-gameplay showcase.
- Every game card in the website collection now uses its own looping gameplay GIF.
- Terminal FC now has a gameplay preview alongside the other six games.
- Website validation tests were updated for the GIF-based presentation.

## Install or update

No Go installation or source checkout is required. Download the archive for your OS and CPU and verify it against `SHA256SUMS`, or update through Homebrew/Scoop after their manifests point to this release.

```sh
brew update
brew upgrade cagridursun/devcade/devcade
devcade --version
```

```powershell
scoop update
scoop update devcade
devcade --version
```

The expected version is `devcade 1.0.0-rc.4`. Existing profiles, preferences and personal bests are retained.

## Deployment and verification

The shared HTTPS leaderboard endpoint remains `https://devcade.cinesdigital.com`.

The release workflow builds six platform archives for Windows, macOS and Linux on amd64 and arm64, verifies checksums and installers, runs the native test matrix, and validates packaged binaries before publication.

An interactive terminal of at least 80 × 24 is required. Binaries remain unsigned and are not notarized. DevCade is licensed under MIT and each archive includes the project and third-party license notices.
