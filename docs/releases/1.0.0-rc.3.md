# DevCade 1.0.0-rc.3

This release candidate expands DevCade from four to seven playable games with Brick Breaker, Terminal FC and Space Shooter, while preserving the existing catalog order and profiles.

## New games

- **Brick Breaker** is game #5: ten progressively harder levels, durable bricks, six bonuses, multiball, combos and local/global best scores.
- **Terminal FC** is game #6: a three-minute 5v5 football match with bot teammates and opponents, ground and lob passes, tackles, pressing, shooting and player switching.
- Terminal FC includes **Easy, Normal and Hard** AI difficulty. Normal is the default; Hard preserves the original aggressive bot tuning.
- **Space Shooter** is game #7: endless waves, enemy archetypes, boss fights, pickups and a charge-based vertical special attack.

The catalog order is:

1. Snake
2. Block Drop
3. Maze Chase
4. Blast Grid
5. Brick Breaker
6. Terminal FC
7. Space Shooter

## Controls and settings

Terminal FC uses arrow keys for movement, `A` for lob pass/tackle, `S` for ground pass/press, `D` for shoot and `W` for player switch.

Fresh profiles now start with global score sharing and usage statistics enabled. Both options remain independently configurable in Settings, and an explicit saved opt-out remains off after upgrades.

## Install or update

No Go installation or source checkout is required. Download the archive for your OS and CPU and verify it against `SHA256SUMS`, or update through Homebrew/Scoop after their manifests point to this release.

```sh
brew update
brew upgrade cagridursun/devcade/devcade
devcade --version
```

```powershell
scoop update
scoop update devcade
devcade --version
```

The expected version is `devcade 1.0.0-rc.3`. Existing profiles, preferences and personal bests are retained.

## Deployment and verification

The shared HTTPS leaderboard endpoint remains `https://devcade.cinesdigital.com`. The publishing workflow verifies all seven game IDs, builds six platform archives, checks installers and checksums, runs native race tests on Linux, macOS and Windows, and smoke-tests the leaderboard container before publishing.

An interactive terminal of at least 80 × 24 is required. Binaries remain unsigned and are not notarized. DevCade is licensed under MIT and each archive includes the project and third-party license notices.
