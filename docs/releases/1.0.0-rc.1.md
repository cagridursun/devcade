# DevCade 1.0.0-rc.1

The first DevCade release candidate brings four small arcade games into your
terminal: Snake, Block Drop, Maze Chase and Blast Grid.

Download the archive for your OS and CPU, verify it against `SHA256SUMS`,
extract it and run `devcade`. No Go installation or browser is required.
An interactive terminal of at least 80×24 is required.

| Platform | Files |
| --- | --- |
| Windows | `devcade_1.0.0-rc.1_windows_amd64.zip`, `devcade_1.0.0-rc.1_windows_arm64.zip` |
| macOS | `devcade_1.0.0-rc.1_darwin_amd64.tar.gz`, `devcade_1.0.0-rc.1_darwin_arm64.tar.gz` |
| Linux | `devcade_1.0.0-rc.1_linux_amd64.tar.gz`, `devcade_1.0.0-rc.1_linux_arm64.tar.gz` |

`install.sh` and `install.ps1` provide checksum-verifying installation without
administrator rights. [Installation instructions](https://github.com/cagridursun/devcade/blob/main/docs/install.md)
explain direct downloads, PATH setup and uninstalling.

## Play

- `devcade` opens the game menu; `devcade <id>` launches a game directly.
- Arrows/WASD move. Space pauses; Q/Esc leaves; Ctrl+C exits.
- Block Drop: Up rotates clockwise, Z counterclockwise, Down soft-drops,
  Enter hard-drops.
- Blast Grid: Z places a bomb.
- Enter restarts every game after a win or loss.

## Verification and limits

- All six targets are built without CGO. The release workflow checks the
  exact packaged native binaries, checksums, installers and race tests on
  Linux amd64, macOS arm64 and Windows amd64 before publication.
- The owner reports successful Windows gameplay for all four games.
- All four games were driven through a Linux PTY; input, normal quit and TTY
  restoration passed. Detailed human macOS/Linux emulator acceptance remains
  incomplete. ARM64 Windows/Linux and Intel macOS are cross-built, not fully
  tested interactively.
- Binaries are unsigned and not notarized. See the installation instructions
  for checksum verification and OS prompts.
- Scores are per-run only. There are no saves, accounts, network services or
  multiplayer.
- Homebrew and Scoop manifests are generated, but tap/bucket publication is
  not part of this release. `brew install devcade` and `scoop install devcade`
  are not yet available.
